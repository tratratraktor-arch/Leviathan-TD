# Leviathan TD

Пиксельный 2D tower defense в одном HTML-файле. Без сборки и зависимостей.

## Структура
- `index.html` — вся игра: код, графика (рисуется процедурно), баланс.
- `media/` — музыка и другие медиафайлы.

## Запуск локально
Открой `index.html` в браузере. Если музыка не играет из-за ограничений `file://`,
запусти простой сервер в папке игры: `python3 -m http.server 8000` и открой http://localhost:8000.

## Публикация через GitHub Pages
1. Залей содержимое этой папки в корень репозитория.
2. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.
Эту ссылку потом можно открыть из Telegram-бота как Mini App.

## Сохранения
Профиль хранится в localStorage браузера (`leviathanProfile`), настройки — в `leviathanSettings`.
